# Ícone

O ícone do KeveOQ: uma pipoca estufada e sorridente em forma de balão de fala, em caramelo e creme sobre abóbora (`brand-abobora`, `brand-caramelo`, `brand-creme`). Copiado do canvas de identidade visual, sem alterações.

- **keveoq-icone-quadrado.svg** — ícone completo com cantos arredondados, como aparece na maioria dos launchers.
- **keveoq-icone-circular.svg** — o mesmo desenho na máscara circular.
- **keveoq-icone-monocromatico.svg** — versão de uma cor para os ícones temáticos do Android 13+ (o sistema recolore conforme o tema do usuário). Tinta: `secondary` (#23525E) sobre `secondary-container` (#CDE7EC), olhos e sorriso vazados.

No app, o ícone é adaptativo: fundo `#E8661E`, camada de frente com a pipoca dentro da zona segura de 66dp (de um quadro de 108dp) e camada monocromática separada. As cores de marca valem só para o ícone e ilustrações.
